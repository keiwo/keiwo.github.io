这个话题更多是探讨健康养肤。

近两年来，我几乎没有做任何护肤了。以下是我皮肤发生状况到如今还算稳定的全部过程。

<span style="font-size: 24px; color: rgb(255, 169, 0); font-weight: bold">01</span>

我的个人情况：从小到大皮肤光滑，无斑无痘无红血丝，黄一白，皮肤较抗造。长于山西，本科内蒙，硕士东北。皮肤状况一直良好。于南京工作后，皮肤情况开始恶化。

<span style="font-size: 24px; color: rgb(61, 170, 214); font-weight: bold">02</span>

硕士毕业后从北到南的居住环境大变动，让我之后皮肤相关产生了任何问题都精准扣上“水土不服”的帽子，比如我刚到南京时全身皮肤红敏、蚊子叮咬后全身肿包等等。因为皮肤是人体的最外层屏障，所以更像是身体问题的放大镜。

<span style="font-size: 24px; color: rgb(215, 171, 169); font-weight: bold">03</span>

外用或者不用任何护肤品都会定期引发爆发性闭口，红痘。集中体现在额头、下巴，后蔓延至两颊。

<span style="font-size: 24px; color: rgb(121, 123, 170); font-weight: bold">04</span>

一段时间内，停用所有的护肤品，靠天然养肤。

<span style="font-size: 24px; color: rgb(255, 127, 170); font-weight: bold">05</span>

皮肤老龄化加速，肤色晒黑暗沉，细纹增多。闭口痘痘几乎没有改善。

<span style="font-size: 24px; color: rgb(122, 68, 66); font-weight: bold">06</span>

反观自己在皮肤出现问题的第一时间确实除了洁面乳正常使用外停掉了包括防晒在内的所有护肤。咨询过东北、山西以及江苏地区皮肤科医生请求帮助。年初还去过南京皮研所。三个地方给出的诊断，意见不一。由于诊断时间内，痘痘情况不完全一样，所以各个地方判断的依据不同，导致不能做到平行问诊。总结来说就是脂溢性皮炎、过敏性皮炎、玫瑰痤疮。一时间我知道自己皮肤出现了很大的问题，但却不明确到底是哪一种。

于是我拿着三个地方分别开出的药剂（外用加内服均有）开启了长达一年的药物辅助治疗。并且买了市面上较有名气的护肤产品，主打功效是针对于我皮肤问题的。结果均没有成效。

<span style="font-size: 24px; color: rgb(214, 168, 65); font-weight: bold">07</span>

偶然的机会查了一下大同和南京的水源地，发现水质存在很大差异，开始尝试洗脸后用纯净水擦拭一遍，大约坚持了一个月，脸部情况开始逐步好转，由于这期间我在积极学习皮肤相关知识，也换掉了一系列护肤品，目前在用国产某护肤品。解决了南方湿热、面部出油闷痘等问题。面部皮肤具有维持平衡的水油比例，当护肤品补水效果不佳时会出现外油内干的症状，大量油脂堵塞毛孔后便会堆积闭口；当补水效果大大加强，皮肤渗透压失衡，便会出现闷痘的情况。任何的皮肤问题都源于水、油失衡，不管是面部皮肤自身，还是护肤品中的配料比例。庆幸的是我终于选对了产品。总结来说：纯净水＋精简护肤＝皮肤恢复。

<span style="font-size: 24px; color: rgb(121, 123, 170); font-weight: bold">08</span>

现在每周正常敷面膜，每晚睡前半支精华，每天水乳后涂防晒霜。偶尔闭口时擦拭一次阿达帕林，每周擦拭一次酸A乳。基本上趋于稳定，甚至可以正常化妆，也祝大家拥有一个好皮肤，好心情。
